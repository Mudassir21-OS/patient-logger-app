PATIENT LOGGER - iPhone web app (free, offline, no App Store)

Put it online once (free):
  GitHub Pages: create a public repo, upload ALL files in this folder (keep the folders),
  Settings > Pages > Deploy from branch "main" / root. Your link: https://<username>.github.io/<repo>/
  (or Netlify: app.netlify.com/drop - drag this folder in, sign up free so the site stays online)

On the iPhone (Safari):
  open the link > Share > Add to Home Screen > open it from the Home Screen icon.
  From then on it works offline. Patient data never leaves the phone.

Use: tap the Speak box > tap the keyboard microphone > say
  "Ahmed Khan, 45872, 45, male, fever"  > check > Save patient.
Export & more tab: monthly Excel workbook, export day/everything, backup file, restore,
Recently deleted, settings. Records are never removed unless "Recently deleted" is erased.

Updating the app later: change files, bump VERSION in sw.js, upload again. Data on phones is kept.
Never change the web address - phone data belongs to that address (make a backup first if you must).
