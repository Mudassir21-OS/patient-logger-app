    Export to Excel

    Every record stays in the app – exporting only makes a copy. Send the file by AirDrop, email or WhatsApp, or save it to Files.

    Backup

    Records are stored only on this iPhone. Save a backup file to Files or iCloud Drive now and then. You can restore it here or on a new phone.

    Settings

    Set both to the hospital's exact ID length for the strictest check.

    Help: what to say

    • “Ahmed Khan, 45872, 45, male, fever” – no keywords needed. Say the name first, then ID, age and gender in any order, and the diagnosis last.
    • Keywords still work: “Name … ID … age … gender … diagnosis …”
    • End with “and save” to save straight away.
    • Fix a box: keep talking – “ID 45873” or “age 46” – the last one said wins. Or just type in the box.
    • Spell a name: “spell A H M E D space K H A N”
    • Babies: “6 months old” is saved as 6m
    • Voice commands (said alone): “save”, “next patient”, “delete last”
